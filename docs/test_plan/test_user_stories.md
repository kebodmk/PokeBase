# Pokebase Testing Criteria

| ID | User Story | Size (Points) |
|----|------------|------|
| US-01 | As a new user, I want to create an account so that I can use the services of Pokebase and interact with other users. | 2 |
| US-02 | As a registered user, I want to log in and out in a secure way so my information is protected. | 2 |
| US-03 | As a user, I only want to be able to access what I am allowed to based on my role. | 5 |
| US-04 | As a manager of a store, I want to be able to set access levels to other accounts. | 5 |
| US-05 | As a user, I want to be able to add and remove specific cards in my inventory. | 10 |
| US-06 | As a user, I want to be able to search through the cards that are in my inventory. | 10 |
| US-07 | As a user, I want to be able to view detailed information about a card so that I can verify its value and characteristics. | 9 |
| US-08 | As a manager, I want to be able to update the condition of a card so that my inventory accurately reflects its quality. | 6 |
| US-09 | As a manager, I want to view inventory change history so that I can track who modified inventory records. | 5|
| US-10 | As an employee, I want to purchase/sell cards from/to customers so that inventory can be replenished. | 10 |
| US-11 | As a manager, I want all completed transactions recorded so that sales history can be reviewed. | 6 |
| US-12 | As a cashier/employee, I want inventory quantities automatically updated after a completed sale so that stock levels remain accurate. | 8 |
| US-13 | As a manager, I want to view daily reports to monitor store performance. | 5 |
| US-14 | As a manager, I want to be able to see the total inventory value so that I can understand my store's assets. | 7 |
| US-15 | As a manager, I want to search past transactions so that I can investigate customer issues and inventory discrepancies. | 6 |
| US-16 | As an employee, I want the ability to calculate data on a card from a picture. | 5 |
| US-17 | As a user, I want to be able to scan a card to retrieve and display information on that card. | 8 |
| US-18 | As an employee, I want to be able to scan cards on checkout to rapidly add them to a transaction. | 4 |
